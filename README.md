### 📋 نظرة عامة
* **المعمارية:** تطبيق محلي بالكامل (Offline-First) لا يرفع بيانات المستخدمين أو سجلاتهم المالية إلى أي خوادم خارجية.
* **الأمان:** حماية البيانات محلياً وتشفير قواعد البيانات وحماية القفل البيومتري.
* **الامتثال:** متوافق تماماً مع إرشادات ومتطلبات متجر Google Play (Developer Program Policies) وسياسات بيانات المستخدم الحساسة (Personal and Sensitive User Data).
